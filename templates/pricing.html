Common questions

How does the free plan work?
Create an account and connect your GitHub repo. PatchPilot monitors up to 1 repo for changes in Stripe, Twilio, and OpenAI — forever free. No credit card needed.
What happens when an API breaks?
PatchPilot detects the change, scans your codebase using AST analysis to find affected files, generates a fix using a local LLM, and opens a pull request on GitHub. You review and merge.
How do I upgrade to Pro?
Email jayam@patchpilot.dev and we'll set you up within 24 hours. Stripe payment integration is coming soon.
Does PatchPilot store my source code?
No. PatchPilot reads your code temporarily to scan for patterns and generate a patch. We don't store your source code permanently. See our Privacy Policy.
Which APIs do you monitor?
Currently: Stripe, Twilio, OpenAI, Plaid, SendGrid, Slack, GitHub API, Anthropic, and Shopify. More are added regularly. Don't see yours? Request it.
Can I cancel anytime?
Yes. Email us and your plan reverts to Free immediately. Your repos and history stay intact.
